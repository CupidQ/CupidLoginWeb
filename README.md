
# CupidQ · 账号中心

**布道自由。**

一个用于学习和面试演示的登录、注册项目。前端使用原生 HTML、CSS、JavaScript，后端使用 Go 标准库提供网页与 HTTP 接口，密码使用 bcrypt 加盐哈希保存。

## 运行方式

### 环境要求

- Go 1.27.0 或更高版本（以 `go.mod` 为准）。
- 支持现代 JavaScript、Canvas 和 Web Animations API 的浏览器。
- 首次启动需要联网下载 Go 依赖 `golang.org/x/crypto`。

无需安装 Node.js、npm 或前端构建工具。

### Windows PowerShell

在项目根目录打开 PowerShell，执行：

```powershell
.\start.ps1
```

启动后，浏览器访问 [http://127.0.0.1:8080/](http://127.0.0.1:8080/)。在运行服务的终端按 `Ctrl+C` 停止。

启动脚本会切换到项目目录，并将 Go 构建缓存、模块缓存和 GOPATH 放入 `.cache/`；这些环境变量仅影响当前进程及其子进程，不修改系统全局配置。

### 直接使用 Go

在项目根目录执行：

```sh
go run .
```

此方式适用于 Windows、macOS 和 Linux，但本项目的既有验证环境为 Windows。必须从项目根目录启动，因为服务通过相对路径读取 `web/`。

请通过 Go 服务访问网页，不要直接双击 `web/index.html`，否则注册与登录接口不能正常使用。修改前端文件后刷新网页即可；修改 Go 文件后需要停止并重新启动服务。

## 使用流程

1. 默认进入登录页面，点击“立即注册”切换到注册表单。
2. 填写账号、密码和确认密码，点击“注册”。
3. 关闭注册成功弹窗后，点击“立即登录”；账号会自动填入登录表单。
4. 重新输入密码并登录，结果通过浏览器原生 `alert` 弹窗显示。

### 输入规则

- 账号会去除首尾空格，区分大小写，最多 40 个字符。
- 密码保留首尾空格，但不能全部为空白，最多 72 个 UTF-8 字节。
- 注册时，两次密码必须一致；确认密码只在前端校验，不发送到后端。
- 空白输入框初次失焦不会提示必填；提交时统一检查，已有错误会随输入更新。
- 请求期间禁用表单控件，避免重复提交；请求超时时间为 10 秒。

### 注册彩蛋

在注册页面填写账号 `ncuhome`，点击注册，会弹出彩蛋提示，确认后跳转到 [南昌大学家园网](https://home.ncu.edu.cn/)。该分支在常规表单校验之前执行，不受密码内容影响，也不会调用注册接口创建账号。

## 界面功能

- 居中的登录、注册卡片，支持窄屏布局。
- 昼夜主题切换：分别使用白天、黑夜背景图，等比铺满视口并自动裁剪。
- 背景、顶部和底部遮罩渐变，以及太阳与月亮图标过渡。
- 登录与注册之间淡出、滑入，卡片高度同步变化。
- 密码显示与隐藏，配有睁眼、闭眼动画。
- Canvas 粒子连线：初始化时视口宽度小于 600px 使用 100 个粒子，否则使用 250 个；鼠标作用范围为 60px。
- 粒子随主题平滑变色；吸附采用连续权重，并在统一更新位置后绘线，减少抽动。
- 标签页进入后台时停止粒子动画；系统启用“减少动态效果”时关闭相关动画。

## 代码阅读顺序

建议先阅读 `index.html` 了解页面元素，再阅读 `style.css` 理解布局；接着沿 `app.js` 中的事件绑定找到表单校验和提交函数，最后阅读 `main.go` 中对应的接口处理。

一次普通提交的流程是：

```text
点击提交 → 前端校验 → fetch 发送 JSON
       → Go 校验请求 → 注册或验证密码 → 返回 JSON → alert 显示结果
```

`cursor.js` 独立负责装饰动画，可以在理解登录注册主流程后再阅读。它继承本地的 CanvasNest，并拆分位置更新与连线绘制；第三方库源码保留原样。

## HTTP 接口

前端和接口由同一个 Go 服务提供，使用相对路径请求，不需要额外配置跨域。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/` | 登录注册网页及静态资源 |
| POST | `/api/register` | 创建账号 |
| POST | `/api/login` | 校验账号和密码 |

两个 POST 接口使用相同的 JSON 请求格式：

```json
{
  "username": "example",
  "password": "your-test-password"
}
```

响应格式：

```json
{
  "message": "登录成功，欢迎回来！"
}
```

| HTTP 状态码 | 含义 |
| --- | --- |
| 200 | 登录成功 |
| 201 | 注册成功 |
| 400 | 请求格式或输入不符合要求 |
| 401 | 密码错误 |
| 404 | 账号不存在 |
| 405 | 认证接口使用了非 POST 方法 |
| 409 | 注册账号已存在 |
| 500 | 密码哈希生成失败 |

后端限制请求体大小为 4096 字节，拒绝未知 JSON 字段和多余 JSON 内容。账号存储通过互斥锁保护；生成密码哈希后再次检查账号是否存在，避免并发注册覆盖同一账号。

## 测试与检查

在项目根目录执行：

```sh
go test ./...
go vet ./...
```

如果需要使用项目内缓存，可先在 PowerShell 中执行：

```powershell
$env:GOCACHE = Join-Path $PWD '.cache\go-build'
$env:GOMODCACHE = Join-Path $PWD '.cache\go-mod'
$env:GOPATH = Join-Path $PWD '.cache\go'
```

现有 Go 测试覆盖注册、登录、重复账号、账号不存在、密码错误、空输入、非法与多余 JSON、超长密码、密码哈希和随机盐，以及同一账号的并发注册。

前端交互使用浏览器手动检查：登录注册切换、输入校验、密码显示、昼夜动画、粒子效果和响应式布局。当前没有提交独立的前端自动化测试套件。

## 常见问题

- **提示找不到 `go`**：确认已安装 Go，并重新打开终端，使用 `go version` 检查。
- **PowerShell 禁止执行脚本**：可在项目根目录直接使用 `go run .`，无需为本项目修改系统执行策略。
- **8080 端口被占用**：检查是否已有本项目服务运行，停止旧实例后重试。
- **页面无法连接服务**：确认终端中的 Go 服务仍在运行，访问地址为 `http://127.0.0.1:8080/`。
- **重启后账号不存在**：当前使用内存存储，重启会清空账号，需要重新注册。

## 当前范围与限制

本项目是登录注册流程演示：账号与密码哈希仅保存在服务端内存，没有数据库或磁盘持久化。登录成功只返回提示信息，不创建 Session 或 Token，也没有登录后的受保护页面。

服务只监听本机 `127.0.0.1:8080`。未实现验证码、找回密码、第三方登录或登录限流；当前实现不作为可直接部署的生产认证系统。
